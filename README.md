# dotfiles

Minimal Arch Linux setup built around the [niri](https://github.com/niri-wm/niri) scrollable Wayland compositor — riced, themed, and friendly to beginners.

![vibe](https://img.shields.io/badge/compositor-niri-blue) ![themer](https://img.shields.io/badge/theming-matugen-purple)

## What's inside

| Area | Tools |
|---|---|
| Shell | fish + starship, kitty terminal |
| Desktop | niri, waybar, swaync, rofi |
| Files | yazi (opens with vim / mousepad / zathura / mpv / imv) |
| Media | mpv, imv, zathura |
| Theming | matugen → every accent color follows your wallpaper |
| Wallpapers | auto-rotate on login, rofi picker with live previews (`Mod+Shift+W`) |
| Extras | click sounds, OCR tools, eye-care night light, random floating windows |

## Keybindings (beginner guide)

`Mod` = the **Super/Windows** key.

### Getting around
| Keys | Action |
|---|---|
| `Mod+Return` | floating terminal (spawns at a random spot) |
| `Mod+Shift+Return` | floating terminal inside a tmux session |
| `Mod+E` | floating **yazi** file manager |
| `Mod+D` | **rofi** app launcher |
| `Mod+Q` | close focused window |
| `Mod+arrows` or `Mod+hjkl` | move focus between windows/columns |
| `Mod+Shift+arrows` | move the window itself |
| `Mod+1..9` | switch workspace |
| `Mod+Shift+1..9` | send window to workspace |

### Shaping windows
| Keys | Action |
|---|---|
| `Mod+C` | toggle floating/tiling |
| `Mod+F` | maximize column · `Mod+Shift+F` true fullscreen |
| `Mod+R` | cycle preset column widths · `Mod+Shift+R` window height |
| `Mod+Minus` / `Mod+Equal` | shrink / grow column width |
| `Mod+[` / `Mod+]` | consume windows into / expel from current column |

### The fun stuff
| Keys | Action |
|---|---|
| `Mod+Shift+W` | **wallpaper picker** — rofi grid with previews; picking one re-themes the whole desktop |
| `Mod+W` | toggle waybar visibility |
| `Mod+Shift+S` | toggle mouse click sounds |
| `Mod+S` | OCR a screen region → text to clipboard |
| `Mod+Shift+Z` | OCR + translate a region |
| `Mod+Shift+T` | OCR fullscreen → copy all text |
| `Mod+V` | zoom lens over a screen region |
| `Mod+Shift+C` | clipboard history picker (cliphist) |

## Wallpapers

A **desert wallpaper** ships with the repo so you never stare at niri's gray void. It lands in `~/Pictures/Wallpapers/` on install.

- **Automatic**: wallpapers rotate on login and keep rotating while you work — just drop any `.jpg` `.png` `.webp` into `~/Pictures/Wallpapers` and they join the pool instantly.
- **Manual**: `Mod+Shift+W` opens a rofi grid with image previews; pick one and it applies with a smooth transition.
- **Theming bonus**: choosing a wallpaper extracts its brightest accent color and regenerates the theme for waybar, rofi, kitty, fastfetch and niri via matugen — the whole desktop recolors itself.

## Install

```bash
git clone https://github.com/sarok-exe/dotfiles.git
cd dotfiles
./install.sh
```

The installer backs up any conflicting files in `~/.config`, symlinks everything into place, and seeds `~/Pictures/Wallpapers`.

## Optional packages

```bash
sudo pacman -S --needed niri kitty fish starship waybar swaync rofi-wayland \
  yazi zathura zathura-pdf-mupdf mpv imv mousepad matugen fastfetch awww \
  wl-clipboard cliphist grim slurp tesseract tesseract-data-eng wlsunset \
  eza imagemagick
```

## Notes

- Theming is generated by `matugen` — change your wallpaper and every accent color follows.
- `Mod+Return` opens a floating terminal at a random position; `Mod+E` does the same for yazi.
- OCR binds need `tesseract`; translation additionally uses `chrome-lens-py`.
- Wallpaper transitions are powered by `awww` and the blurred backdrop effect needs `imagemagick`. The picker re-themes everything through matugen — no extra Python deps needed.
